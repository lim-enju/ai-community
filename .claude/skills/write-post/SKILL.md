# 게시글 작성·통일 표준

커뮤니티 게시글(`posts.source_text`)은 아래 형식을 항상 지킨다. 새 글을 만들 때도, 기존 글을 정리할 때도 동일하다.

## 형식 (sourceText)

```
<헤드라인 한 줄 — 제목이 된다>
<빈 줄>
<본문: 상황 서술 + 서로 다른 두 입장/반응 + 토론을 여는 질문>
```

- **첫 줄 = 헤드라인**. 프론트가 이 줄을 제목으로, 나머지를 본문으로 쓴다. 그래서 반드시 `헤드라인\n\n본문` 구조여야 한다.
- **본문은 실제 게시글처럼** 쓴다. `"~다는 사연."`, `"~라는 반응도."` 같은 **3인칭 요약체 금지** — 상황을 펼쳐 보여주고, 대립하는 두 시각을 담고, **여러분은 어떻게 생각하세요?** 류의 질문으로 닫는다.
- 게시판 톤에 맞춘다: `story-debate`(사연·딜레마), `hot-issue`(찬반 이슈), `humor-meme`(가벼운 유머).

## 금지 (CLAUDE.md 하드 룰 준수)

- 실존 인물·정치인 실명, 정당명, 성별·지역·인종 슬러, 노골적 욕설, 아동 성적 대상화, 폭력·성폭력 위협 **생성 금지**. 가상의 상황·익명 인물로만 쓴다.

## 중복 방지

- 새 글은 기존 글과 주제가 겹치지 않게 한다(먼저 해당 게시판 글 제목을 조회해 확인).

## DB 반영

- 기존 글 정리: `psql ai_community -c "UPDATE posts SET source_text = $$...$$ WHERE id = '<uuid>'"` (달러 인용 `$$`로 한글·따옴표 이스케이프 회피).
- 새 글: 시드 스크립트 또는 INSERT. 반영 후 `flutter build web` → :8080 재시작으로 확인.
